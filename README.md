# Claude Pet 🐾 (윈도우)

Claude Code가 지금 뭘 하는지, 사용량이 얼마나 남았는지 알려주는 **데스크톱 펫**이에요.
화면 위에 작은 캐릭터가 떠 있고, 일하는 중이면 같이 일하고, 허용이 필요하면 알려줘요.

> 비공식 개인 프로젝트예요. Anthropic과 관련이 없고, 캐릭터는 Claude Code의 마스코트를 떠올리게 직접 그린 그림이에요(공식 이미지가 아니에요).

## 가장 쉬운 설치: Claude 에게 맡기기
Claude Code(또는 Claude 데스크톱 앱의 Code 탭)에서 이렇게 말하면 끝이에요.

> https://github.com/Harub/claude-pet-win 설치해줘

Claude 가 저장소의 `INSTALL.md` 를 읽고 받기부터 설치, 실행까지 알아서 해요. 필요한 건 Claude Code 와 인터넷뿐이에요. (Node.js 가 없으면 Claude 가 설치해요)
직접 설치하고 싶다면 아래 "설치 (3분)"를 따르세요.

## 필요한 것
- Windows 10 / 11
- [Node.js](https://nodejs.org/ko) 18 이상 (설치할 때만 필요해요. LTS 버전을 받으세요)
- Claude Code (터미널의 `claude`). 윈도우용 Claude Code는 [Git for Windows](https://git-scm.com/download/win) 가 있어야 동작하는데, 펫도 Claude Code가 쓰는 그 환경(Git Bash)으로 신호를 받아요.

## 설치 (3분)
1. 이 저장소를 받아서(Code 버튼 → Download ZIP) 압축을 풀고, 폴더를 원하는 곳에 두세요. 설치한 뒤에도 지우지 말고 그 자리에 두세요. (예: `C:\Users\내이름\Developer\claude-pet`)
2. **`install.bat`을 더블클릭**하세요. "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**을 누르세요. (서명되지 않은 개인 프로그램이라 처음에만 떠요)
3. 검은 창이 열리고 설치가 진행돼요. 몇 분 걸려요. 끝나면 펫이 화면에 나타나요.
4. Claude Code 세션을 **새로 시작**하세요. 이미 켜져 있던 세션에는 적용되지 않아요.

다음부터는 시작 메뉴에서 **Claude Pet**을 실행하면 돼요. Claude Code 세션을 시작할 때 펫이 꺼져 있으면 자동으로 켜져요. (`/clear`나 대화 정리로 다시 시작될 때는 켜지 않아요)

## 펫이 알려주는 것
| 펫 모습 | 의미 |
|---|---|
| 숨쉬며 대기 | 쉬는 중. 마우스를 따라 눈이 움직여요 |
| 점 세 개 | 생각 중 |
| 노트북 두드림 | 도구 실행 중 |
| 망치질 | 파일을 만들거나 고치는 중 |
| 헤드폰 / 저글링 | 서브에이전트 1개 / 2개 이상 |
| X 눈 + 땀방울 | 도구 실행이 실패했어요 |
| 빗자루질 | 대화 정리 중 |
| 주황 카드 ✋ | **허용이 필요해요** (30초 넘게 기다리면 마우스 옆을 따라다녀요) |
| 반짝이 | 작업 끝 |

말풍선에는 세션 이름, 프로젝트, 지금 하는 일, 끝났을 때는 답변 첫 줄이 나와요. 펫 아래 막대는 5시간/주간 **사용량**이에요.

## 사용법
- **드래그**: 아무 곳이나 옮길 수 있어요. 위치를 기억해요.
- **더블클릭 / 말풍선 클릭**: 그 세션을 Claude 데스크톱 앱에서 열어요. (Claude 데스크톱 앱이 깔려 있을 때만 돼요)
- **화면 가장자리로 끌어다 놓기** 또는 우클릭 → 미니 모드: 가장자리에 숨어 있다가 마우스를 올리면 튀어나와요. 숨은 채로도 `작업 중…` / `완료`는 작게 보여줘요.
- **우클릭 메뉴**: 위치 초기화, 미니 모드, 방해 금지(잠들기), 로그인 시 자동 실행, 사용량 조회 끄기, 종료.
- 60초 가만히 있으면 졸아요. 마우스를 가까이 가져가면 깜짝 놀라며 깨요.
- 작업 표시줄에는 아이콘이 없어요. 종료는 펫 우클릭 → 종료예요.

## 이 앱이 하는 일 (개인정보)
모두 **내 컴퓨터 안에서만** 동작해요. 서버나 계정이 없고, 분석/수집도 없어요.
- **Claude Code 설정 변경**: `%USERPROFILE%\.claude\settings.json`에 훅(이벤트를 펫에 알려주는 한 줄 명령)과 상태줄을 추가해요. 바꾸기 전에 백업(`settings.json.claude-pet.bak-…`)을 만들어요. 제거하면 원래대로 돌아와요.
- **내 컴퓨터 안의 통신**: 훅이 `127.0.0.1:3199`(이 컴퓨터 안)로만 이벤트를 보내요.
- **읽는 파일**: 세션 제목/답변 첫 줄을 보여주려고 Claude Code 대화 기록(`%USERPROFILE%\.claude\projects\…jsonl`)의 끝부분과 Claude 앱이 저장한 세션 정보를 읽어요. 읽기만 하고 어디에도 보내지 않아요.
- **사용량 조회(켜져 있음)**: Claude Code 로그인 파일(`%USERPROFILE%\.claude\.credentials.json`)의 토큰을 **읽어서** `api.anthropic.com`에 사용량만 물어봐요. 토큰은 저장하지 않고 다른 곳으로 보내지 않아요. 원하지 않으면 우클릭 메뉴에서 `로그인 정보로 사용량 조회`를 끄세요. 공식 문서에 없는 방식이라 언젠가 안 될 수 있어요.
- **로그인 만료 시 자동 갱신(꺼져 있음)**: 켜면 로그인이 만료될 때 `claude`에 아주 짧은 요청을 한 번 보내 스스로 갱신하게 해요. 사용량이 몇 토큰 들어요. 우클릭 메뉴에서 켤 수 있어요.

## 점검
뭔가 안 보이면 이 폴더에서 터미널(PowerShell)을 열고 `npm run doctor`를 실행해 보세요. 어디가 문제인지 알려줘요.

## 제거
`uninstall.bat`을 더블클릭. 훅과 앱을 지워요. (`.claude-pet` 데이터는 물어보고 지워요)

## 업데이트
Claude 에게 "claude-pet 업데이트해줘"라고 하거나, 새 버전을 받아서 `install.bat`을 다시 실행하세요. 설정은 그대로 이어져요.

## 알아둘 점
- 지원하는 건 Claude Code 세션이에요. claude.ai의 일반 채팅과 클라우드 세션은 볼 수 없어요.
- 앱이 서명되지 않은 개인용 앱이라 자동 업데이트되지 않아요.
- 허용/거부를 펫에서 직접 누르는 기능은 없어요. 카드를 누르면 Claude 앱의 해당 세션이 열려요.
- 사용량 막대는 터미널의 `claude`에서 가장 확실하게 들어와요. Claude 데스크톱 앱의 Code 탭만 쓸 때는 로그인 파일이 있어야 사용량이 보여요.
